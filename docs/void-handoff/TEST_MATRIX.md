## Evidence rule

Every result needs exact steps/command, build SHA, fixture hash, OS/toolchain/device/driver/plugin/model details, observed output and result-artifact paths/hashes. Screenshots supplement numerical/audio evidence. `blocked` and `not_run` are not passes. See `schemas/evidence.schema.json` and its explicitly unexecuted example.
